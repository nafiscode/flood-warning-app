# Logos on the credits page

These files are shown on `/how-it-works#credits` ("How Jaga works: the science"), beside the entry
for each organisation whose open data Jaga is built on. They are here for **attribution**: naming
and showing the source of the data, as several of the licences ask. None of these organisations
runs, checks or endorses Jaga, and the page says so.

Only marks that Wikimedia Commons holds as public domain or under a free licence were taken
(owner's decision, 16 October 2026). Where a brand has rules of its own that we have not asked
about — the European space agencies, Esri, Google — the credit card draws the organisation's
initials instead, and no file of theirs is in this repository.

The SVG files are as published. The raster files were resized to 128 px and re-encoded as WebP, so
that the whole set costs about 100 KB on a slow connection; nothing else about them was changed.

A trademark stays its owner's whatever the file's licence says. If an organisation here would
rather its mark were not shown, write to the project address on the page and the file is removed
the same day; the card then carries its initials, as the others do.
